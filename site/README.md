# BORIS — внутренний визуальный черновик

Статическая одностраничная версия на HTML, CSS и vanilla JavaScript. Папка `site/` специально подготовлена как самостоятельный корень проекта для Vercel.

## Локальный просмотр

Из корня репозитория:

```bash
python3 -m http.server 8080
```

Открыть http://localhost:8080/site/.

Или открыть `index.html` из этой папки напрямую в браузере. Сборка и Node.js не нужны.

## Vercel

При импорте репозитория `tagirthinktech/boris` в Vercel укажи:

- **Root Directory:** `site`
- **Framework Preset:** `Other`
- **Build Command:** пусто / No Build Command
- **Output Directory:** по умолчанию (корень проекта)

Внутри `site/assets/processed/web/` лежат только 21 локальная фотография, используемая страницей. Это делает папку автономной: Vercel не требуется читать файлы за пределами Root Directory. Остальные каталоги репозитория (включая `docs/`, `research/` и исходный PDF) в проект сайта не входят.

`vercel.json` добавляет HTTP-заголовок `X-Robots-Tag: noindex, nofollow, noarchive`. На странице также есть meta robots. Это черновик для просмотра владельцем, а не утверждённый публичный сайт. Ссылка на Vercel Preview не является парольной защитой: любой, у кого есть URL, сможет открыть страницу.

## Структура

- `index.html` — содержание страницы.
- `styles.css` — адаптивная стилизация.
- `script.js` — мобильное меню, появление секций и лайтбокс.
- `assets/processed/web/` — локальные фотографии, показанные на странице.
- `screenshots/` — скриншоты локального черновика.

## Важные ограничения

Фото, авторство, контекст и права на публикацию всё ещё требуют подтверждения Борисом. Фонтан-колонна показан только как концепция: технически проверена только подсветка; вода, туман, конструкция и прочие системы требуют прототипирования и инженерной проверки. Цена, сроки, гарантия и контакты не публикуются.
