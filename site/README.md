# Сайт BORIS — внутренний черновик (issue #5)

Первый визуальный черновик одностраничного сайта авторской мастерской.
**Внутренний preview для обсуждения: не деплоить в публичный интернет, не подключать домен.**

## Как запустить локально

**Способ 1 — без сервера:** открыть файл `site/index.html` в браузере двойным кликом.

**Способ 2 — через локальный сервер** (рекомендуется, идентично production-среде):

```bash
# из корня репозитория:
python3 -m http.server 8080
# затем открыть http://localhost:8080/site/  (или просто http://localhost:8080/ — редирект)
```

Дополнительных сборок, Node.js и зависимостей не требуется.

## Стек и почему он выбран

Plain **HTML + CSS + один vanilla-JS-файл** без фреймворков и сборки:
- мгновенный запуск и простая проверка в любом браузере;
- нет тяжёлых UI-библиотек и node_modules в репозитории;
- весь код читаем и правится текстовым редактором (см. комментарии в `index.html`);
- для первого визуального черновика сложный стек не нужен. Если позже потребуется
  компонентная архитектура/CMS — переводить можно осознанно, на утверждённом контенте.

## Что где лежит

| Файл | Назначение |
|---|---|
| `index.html` | Единственная страница, все разделы и тексты. Комментарии в коде отмечают, где менять тексты, карточки и изображения. |
| `styles.css` | Дизайн-система: палитра (минеральный белый/графит/бронза), типографика (Cormorant Garamond + Manrope), сетки, адаптив (1100/860/620 px). |
| `script.js` | Мобильное меню, мягкое появление блоков (с учётом `prefers-reduced-motion`), лайтбокс галереи. |
| `screenshots/` | Скриншоты preview (desktop/tablet/mobile). |

Шрифты грузятся с Google Fonts; без интернета страница корректно работает на системных
фолбэках (Georgia/системный sans) — в офлайн-окружении в консоли будет единственная
сетевая ошибка на запрос шрифтов, это ожидаемо.

## Что пока условное и требует решения владельца

- **Все подписи к работам** — нейтральные и намеренно без названий проектов, заказчиков,
  городов и дат: авторство/контекст/права каждого кадра не подтверждены.
- **Тексты разделов** — редакционные формулировки на основе интервью, не утверждённый бренд-контент.
- **Фонтан-колонна** — концепция: технически проверена только подсветка; визуальный блок —
  условная CSS-графика (не фото и не визуализация). Фото/чертежей изделия нет.
- **Контакты** — заглушка «Контакты добавим после согласования». Реальные контакты
  (в т.ч. из PDF-резюме) намеренно не проставлены. Форм обратной связи нет.
- Цены, сроки, гарантия и прочие коммерческие условия на сайте не указаны.
- Название «BORIS» — рабочее обозначение; идея названия из интервью («Ги Спирит»)
  на сайте не используется, логотип не рисовался.
