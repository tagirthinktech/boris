## 3. Инструменты

- Python 3.11 + Pillow 13 (ресайз, контактные листы), pillow-heif (декодирование HEIC), pypdf (текст и встроенные изображения PDF).
- Перцептуальный dhash (8×8) + SHA-256 — поиск точных и похожих кадров, кросс-сверка фото из PDF с фото репозитория.
- Воспроизводимость: `tools/inventory.py` (техинвентаризация) и `tools/generate_derived.py` (веб-копии, миниатюры, контактные листы, HEIC-рабочие копии). Зависимости: `pip install pillow pillow-heif pypdf`.
